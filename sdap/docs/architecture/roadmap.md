# Project Roadmap

- [x] **Phase 0: Foundation** - Monorepo setup, shared packages, initial API scaffold.
- [x] **Phase 1: Authentication** - Registration, Login, Refresh token rotation, Replay detection.
- [ ] **Phase 2: Organizations** - Organization CRUD, Membership, Invitation workflows.
- [ ] **Phase 3: Role-Based Access Control (RBAC)** - Custom roles, permissions, policies.
- [ ] **Phase 4: Vault** - Secure credential and secret storage with delegated access.
- [ ] **Phase 5: Approval Engine** - Policy-based access requests and manager approvals.
- [ ] **Phase 6: Sessions** - Active session management and revocation.
- [ ] **Phase 7: Audit** - Comprehensive audit logging for all security events.
- [ ] **Phase 8: Integrations** - Webhooks, external identity providers (SSO).
- [ ] **Phase 9: MVP Finalization** - Polish, end-to-end testing, readiness for v1.0.0.
